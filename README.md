# HD M

두 개의 창으로 파일을 옮기고 복사하는 윈도우용 파일 관리자입니다.
Mdir For Windows 4.5.591 Beta를 참고하여 2026년에 맞게 재작성한 프로그램입니다.

## 내려받기

[**Releases**](../../releases/latest)에서 받습니다.

- `HDM-5.0.0-setup.exe` — 설치 프로그램(내 계정에만 설치, 관리자 권한 필요 없음)
- `HDM-5.0.zip` — 설치 없이 폴더째 풀어서 쓰는 판

## 주요 기능

- 두 창을 나란히 놓고 파일 복사·이동·삭제, 진행 막대와 Esc 취소
- 드라이브 막대에 드라이브, 휴대폰, OneDrive, Qsync 같은 동기화 폴더, NAS를 단추로 표시
- FTP·FTPS·SFTP 서버를 드라이브처럼 열어 복사·삭제·이름 바꾸기
- 오른쪽 허브: 바로가기, 최근 파일, 빠른 검색
- 휴지통 관리, 일괄 이름 바꾸기, 폴더 크기 계산

## 설치할 때 알아둘 것

- 서명하지 않은 프로그램이라 처음 실행하면 윈도우 SmartScreen이 「알 수 없는 게시자」 경고를 띄울 수 있습니다. **추가 정보 → 실행**을 누르면 됩니다.
- 윈도우 10 이상 64비트에서 동작합니다.
- 설정은 설치 폴더의 `settings.json`에 저장됩니다. 새 버전을 설치해도 덮어쓰지 않습니다.
